Welcome to the KirigamiAnalysis_ReducedOrderModel repository: Code to perform the bar and hinge based simulation for any kirigami systems. 

The bar and hinge discretization employs bars and hinges for three-dimensional analysis, and bars with torsional springs for in-plane modeling. 
Bars represent in-plane deformation, hinges capture out-of-plane bending, and torsional springs provide rotational stiffness. 
This formulation accommodates a range of geometries, boundary conditions, and material properties while maintaining computational efficiency. 
The formulation is developed to capture deformation features characteristic of kirigami, including large deformations, out-of-plane buckling, and in-plane rotational mechanisms.

The repository has the code for single cut kirigami system and for the cellular cut patterns system.
